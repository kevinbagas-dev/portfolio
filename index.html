Tentang Saya

Profil singkat dan area yang saya minati.

Saya merupakan fresh graduate S1 Sistem Informasi Universitas Gunadarma yang tertarik berkarier sebagai Junior Web Developer, System Analyst/Business Analyst, atau QA/Software Tester. Saya memiliki dasar pengembangan web, analisis sistem, pengelolaan database, dan pengujian perangkat lunak.

Melalui proyek akademik website penjualan CakeByVin, saya menggunakan PHP dan MySQL untuk mengembangkan sistem yang mencakup katalog produk, transaksi, dan integrasi payment gateway Midtrans. Proyek ini juga menerapkan rekomendasi produk dengan metode Item-Based Collaborative Filtering dan Cosine Similarity berdasarkan riwayat pembelian.

Saya melakukan Black Box Testing dan User Acceptance Testing (UAT) pada fitur-fitur sistem untuk memeriksa kesesuaiannya dengan kebutuhan. Pengalaman proyek ini menjadi dasar yang ingin saya kembangkan lebih lanjut di lingkungan kerja profesional.
